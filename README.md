# 낙서 용사단 — Notebook Heroes

제공된 기획서 기반의 메인 화면 및 4인 파티 턴제 전투 웹 데모입니다.
Node.js 20 이상에서 외부 패키지 설치 없이 실행합니다.

```sh
cd /workspace/Note_Demo
npm start
```

브라우저에서 실행 서버의 3000번 포트에 접속합니다. `PORT`로 포트를 변경할 수 있습니다.
검증: `npm test`

## 조작
- 첫 번째 모험 시작 → 기사, 마법사, 궁수, 창술사 순서로 행동합니다.
- 공격: MP 소비 없는 기본 공격. 스킬: MP를 소비하는 강한 공격.
- 방어: 다음 반격 피해 65% 감소, MP 5 회복.
- 수호의 창: 공격과 동시에 생존 아군 전체 보호.
- 생존 아군이 모두 행동하면 적이 반격하며, 매 3라운드 강한 전체 공격을 합니다.
- 승리 또는 패배 후 다시 도전하거나 공책 메인으로 돌아갈 수 있습니다.

전투 수치는 데모용입니다. 보상은 결과 화면 표시만 제공하며 저장, 장비, 성장, 추가 챕터는 구현하지 않았습니다.
메인 이미지는 사용자가 제공한 기획서에서 추출했습니다. 캐릭터와 보스도 기획서에 포함된 원본 이미지를 CSS로 부분 표시합니다. 별도 투명 스프라이트가 아니므로 원화의 종이 배경이 포함됩니다.
Google Fonts가 차단된 환경에서는 시스템 폰트로 표시됩니다.

## 애니메이션 데모

`/workspace/exports/Notebook-Heroes-Animated.html`을 다운로드해서 Edge/Chrome으로 열면 됩니다. 단일 파일 안에 코드와 이미지가 들어 있어 서버와 인터넷 연결이 필요 없습니다.

전투 캐릭터는 기획서 디자인을 참고해 Canvas로 재구성했습니다. PDF 원화 그대로의 품질이나 프레임 애니메이션이 아니라, 신체·무기·망토를 분리해 움직이는 절차적 애니메이션입니다. 메인 화면의 그림과 초상화는 제공된 기획서 원화를 사용합니다.

- 대기 동작, 근접 돌진·복귀, 무기 휘두르기
- 화염 검기, 마법탄, 연속 화살, 창격 및 방어막
- 보스 피격, 피해 숫자, 잉크 반격, 화면 흔들림
- 선택형 합성 효과음 (기본 OFF)
- 연출 중 중복 행동 방지, 메인 이동 시 진행 중 연출 취소

배포 파일 재생성: `python scripts/export.py`

## 개선된 캐릭터 리소스

최신 배포 파일은 `/workspace/exports/Notebook-Heroes-Painted.html`입니다. 기획서의 캐릭터를 참고해 생성한 투명 배경의 잉크·수채화 리소스를 메인 초상화와 전투에 적용했습니다. 캐릭터 이동·기울기·대기 움직임과 공격 이펙트는 코드로 제어하며, 개별 관절이나 프레임별 작화 애니메이션은 제공하지 않습니다.
